# Graphical Exercise Results

The figures in this directory are **synthetic/illustrative teaching results**, not measurements from attacks against real systems.

They demonstrate the type of evidence students should produce after completing the exercises.

## Figures

- `exercise-scorecard.svg` — completion/risk score summary
- `service-exposure.svg` — training service exposure profile
- `availability-response.svg` — illustrative response-time change during a bounded availability exercise
- `incident-timeline.svg` — red-team activity and blue-team response timeline
- `detection-matrix.svg` — defensive visibility across exercises

All values are clearly labelled as illustrative so they are not mistaken for empirical measurements.
