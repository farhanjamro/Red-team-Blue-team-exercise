# Assessment Rubric

| Area | Weight |
|---|---:|
| Reconnaissance and service inventory | 20% |
| Web/LAMP analysis | 20% |
| Remote-service/authentication analysis | 15% |
| Controlled availability exercise | 15% |
| Blue-team detection/response | 20% |
| Technical report, evidence and ethics | 10% |

High-quality submissions include timestamps, screenshots/log excerpts, observations, mitigation recommendations and an explicit statement that all testing occurred inside the authorized private lab.
